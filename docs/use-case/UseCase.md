# Use Case 

Use Case Diagram digunakan untuk menunjukkan interaksi antara pengguna (actor) dengan sistem yang sedang dikembangkan. Terlihat beberapa pengguna (actor) yang dapat menjalankan sistem ByBee Project, diantaranya adalah Pengguna, HRD atau Perwakilan Perusahaan serta Admin ByBee Project. Adapun penjelasan mengenai masing-masing aktor tersebut sebagai berikut.

- **Pengguna**, disini pengguna dapat menjalankan beberapa fitur yang terdapat di ByBee Project seperti login website, membuat, mengedit dan mengupload portofolio maupun identitas lainnya serta dapat mencari suatu job atau pekerjaan.
- **HRD atau perwakilan perusahaan**, disini HRD atau perwakilan perusahaan dapat menjalankan beberapa fitur yang terdapat di ByBee Project seperti login website, memposting lowongan pekerjaan, serta mencari kandidat yang sesuai sehingga nantinya dapat diteruskan ke tahapan selanjutnya (interview).
- **Admin ByBee Project**, terdapat dua tugas penting dari admin ByBee Project yakni melakukan maintenance website serta database secara berkala.
